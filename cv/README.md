# CV

- `cv.html`: ต้นฉบับ CV ไฟล์เดียวที่ต้องแก้ ไฟล์นี้ไม่ได้ขึ้นเว็บ
- `../public/CV_PDF.pdf`: ไฟล์ PDF ที่ปุ่ม Resume บนเว็บลิงก์ไป สร้างจาก `cv.html` อย่าแก้ไฟล์นี้ตรงๆ
- `../public/Resume.pdf`: สำเนาของ `CV_PDF.pdf` เก็บไว้ให้ลิงก์เก่าที่เคยส่งให้คนอื่นยังเปิดได้ คำสั่ง `npm run cv:pdf` อัปเดตให้พร้อมกัน

## อัปเดต CV (เช่น ทุกปี หรือเปลี่ยนงาน)

1. เปิด `cv/cv.html` ใน VS Code แล้วแก้ข้อความ
   - แต่ละงานอยู่ในบล็อก `<!-- Job 1 -->`, `<!-- Job 2 -->` ... คัดลอกทั้งบล็อกไปวางด้านบนเพื่อเพิ่มงานใหม่ได้
   - ทักษะอยู่ในส่วน `<!-- Technical Skills -->` และการศึกษาอยู่ใน `<!-- Education -->`
2. ดูหน้าตา: ดับเบิลคลิกเปิด `cv/cv.html` ใน Chrome แล้วกดรีเฟรชทุกครั้งที่แก้
3. สร้าง PDF ใหม่ (ต้องมี Google Chrome และต่ออินเทอร์เน็ต):

   ```bash
   npm run cv:pdf
   ```

   ได้ PDF หน้าเดียวที่ขนาดพอดีกับเนื้อหา (กว้าง 900px สูงเท่าเนื้อหา) ไม่อิงขนาดกระดาษ เพิ่มเนื้อหาเท่าไหร่ หน้าก็ยาวตาม

   ถ้ามีคนขอแบบกระดาษ A4 สำหรับพิมพ์ ให้ใช้:

   ```bash
   npm run cv:pdf -- --a4
   ```

   ถ้าขึ้นว่าเกิน 1 หน้า A4 ให้ตัดข้อความให้สั้นลง หรือลดค่า `zoom` ในส่วน `@media print` ด้านบนของ `cv.html` (ตอนนี้คือ `0.8` ใช้เฉพาะแบบ A4)

4. เปิด `public/CV_PDF.pdf` ตรวจอีกรอบ (`public/Resume.pdf` จะเป็นไฟล์เดียวกัน)
5. Commit แล้ว push ขึ้น GitHub Vercel จะอัปเดตไฟล์บนเว็บให้เอง

อย่าลืมแก้ข้อมูลบนหน้าเว็บให้ตรงกันด้วย ข้อมูลเว็บอยู่ใน `data/profile.ts` (ประสบการณ์, การศึกษา) และ `data/tools.ts` (ทักษะ)
